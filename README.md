# Oridium Ware

Roblox utility script.

## Features

### Main Tab
- Death Aura
- Headless
- Korblox / Remove Korblox

### Movement
- Auto Edge Trimp (230 stud launch, world parts only)
- Auto Bounce (higher)
- Oridium Walk (hold W + Space on walls)
- Oridium Jump (bhop / ramp boost)

### Lighting & Map
- Map Loader
- Model Height / Time of Day / Skybox

### Pshades Shader
- Load PShade Ultimate

## Usage

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/ideBob/OridiumWare/main/OridiumWare.lua"))()
```
