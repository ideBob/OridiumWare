# Oridium Ware

Roblox utility script.

## Features

### Main Tab
- Death Aura
- Headless
- Korblox / Remove Korblox

### Movement
- Auto Edge Trimp
- Auto Bounce

### Lighting & Map
- Map Loader
- Model Height
- Time of Day
- Skybox apply / remove

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/ideBob/OridiumWare/main/OridiumWare.lua"))()
```
